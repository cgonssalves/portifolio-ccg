# 🎓 Cauã Cavalcante — Portfolio

Portfólio pessoal em React com efeito de **livro interativo** (page flip), seção parallax e arquivos acadêmicos.

## Tech Stack
- **React 19** + **Vite 6**
- **Framer Motion** — animações de página
- **React Icons** — ícones
- **CSS Modules** — estilos por componente

## Instalação local
```bash
git clone https://github.com/cgonssalves/portfolio
cd portfolio
npm install
npm run dev
```

## Deploy GitHub Pages
1. Em `vite.config.js`, atualize `base: '/nome-do-repo/'`
2. `npm install --save-dev gh-pages`
3. `npm run deploy`
4. GitHub → Settings → Pages → Source: `gh-pages`
